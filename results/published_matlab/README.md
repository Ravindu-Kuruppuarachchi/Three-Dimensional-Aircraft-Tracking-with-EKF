# Published MATLAB results

These 39 files are unchanged copies of plots and metric tables from 13 MATLAB Online runs: five baseline cases and eight held-out recorded-flight cases. Each run has trajectory_3d.png, errors_nis.png and metrics.csv.

The held-out cases compare q=1 and q=10 on the same observations in the 30–40 and 60–70 minute windows of Belevingsvlucht and Texas. These individual runs are distinct from the repeated-trial averages in the report.

Full per-observation exports, MAT files and raw flight data are excluded. Radar observations are synthetic, and flight coordinates are recorded references with an unverified altitude datum.
